# Pokémon List

A Pokémon list application built with React using the PokéAPI.

## 🚀 Features

- Fetch Pokémon data from PokéAPI
- Display Pokémon names and images
- Loading state while fetching data
- Error handling
- Responsive card layout
- Reusable Pokémon card component

## 🛠 Technologies

- React
- JavaScript
- Fetch API
- Promises
- React Hooks
- PokéAPI
- CSS3

## 📚 What I Practiced

- Working with REST API
- Fetching asynchronous data
- Using `fetch()` and `.then()`
- Using `Promise.all()`
- React `useState`
- React `useEffect`
- Component-based architecture
- Loading and error states
- Passing data through props

## 🌐 API

This project uses [PokéAPI](https://pokeapi.co/) to fetch Pokémon data.
